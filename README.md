# Evaluating Large Language Models for New Product Launch Marketing Decision Support

**A Cross-Domain Analysis of Online Consumer Reviews**

MSc Data Science dissertation, School of Computer Science and Electronic Engineering, University of Surrey (2025-26).

- **Author:** Ankit Verma
- **Supervisor:** Dr Tom Thorne

## Overview

Companies planning a product launch need to know what buyers value, what disappoints them about existing products, and what a credible new proposition would sound like. Online reviews contain this information, but at a volume no marketing team can read.

This project builds and evaluates a **modular, reproducible Python pipeline** that benchmarks traditional NLP methods against a large language model (LLM) for turning raw consumer reviews into **evidence-grounded marketing decision support**. The pipeline is run on two independently sourced product categories to test whether results transfer across domains.

### Datasets

| Domain | Source | Size used |
|---|---|---|
| Beauty | Amazon Beauty reviews | 99,894 reviews (rating-stratified sample from 701,528) |
| Electronics | Datafiniti consumer electronics export | 7,294 reviews |

> The raw datasets are **not included** in this repository. See [Data](#data) below.

### Methods compared

- **Sentiment classification:** VADER (rule-based lexicon), TF-IDF + linear SVM, and a pretrained transformer (`nlptown/bert-base-multilingual-uncased-sentiment`)
- **Topic discovery:** Latent Dirichlet Allocation (LDA) and BERTopic
- **LLM insight extraction:** consumer needs, pain points, satisfaction drivers and launch recommendations, generated under a prompt design that requires every claim to cite supporting review IDs (citations are verified programmatically)
- **Ablation study:** six variants of the TF-IDF + SVM pipeline

## Key findings

- The pretrained transformer classified sentiment best in both domains: macro-F1 of **0.727 (Beauty)** and **0.685 (Electronics)**, against 0.628 / 0.555 for the SVM and 0.514 / 0.469 for VADER.
- Beauty and Electronics sentiment distributions differ significantly (chi-squared = 812.25, df = 2, p < 0.001, Cramér's V = 0.087, a small effect).
- The ablation showed that removing the classical cleaning stage (stopword removal and lemmatisation) **improved** SVM macro-F1 in both domains (0.628 to 0.685 and 0.555 to 0.583).
- **No fabricated citations** were found across 68 LLM-generated entries, but repeated runs on identical input produced **zero exact-text agreement**.
- On Electronics, 21 of 26 extracted insights shift the mean rating of matching reviews in the predicted direction (permutation p = 0.015).
- The human evaluation of usefulness and actionability was designed but **never scored**. Three automated evaluations stand in its place, so conclusions about usefulness are limited.

The pipeline is positioned as **decision support requiring expert review**, not a replacement for marketing judgement. The full write-up is in the dissertation report.

## Getting started

### Prerequisites

- Python 3
- An API key for the LLM stage (`GROQ_API_KEY` or `GOOGLE_API_KEY`)
- Network access on first run, to download the transformer and BERTopic weights and to reach the LLM API

### Installation

```bash
python3 -m venv venv
source venv/bin/activate        # Windows PowerShell: venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Configuration

```bash
cp .env.example .env            # Windows PowerShell: copy .env.example .env
```

Then add your `GROQ_API_KEY` or `GOOGLE_API_KEY` to `.env`. **Never commit `.env`.**

### Data

Place the raw datasets in `data/raw/beauty/` and `data/raw/electronics/`.

## Usage

### Run the full pipeline

```bash
python scripts/run_pipeline.py --domain all
```

### Browse the saved outputs

```bash
streamlit run app.py
```

### Run individual stages

Each stage accepts a `--domain` argument and a refresh flag, which is useful when only one stage needs recomputing.

```bash
python scripts/run_preprocessing.py --domain all
python scripts/run_eda.py --domain all
python scripts/run_sentiment.py --domain all
python scripts/run_ml.py --domain all
python scripts/run_topic_modeling.py --domain all      # add --lda-only to skip BERTopic
python scripts/run_transformer.py --domain all
python scripts/run_llm.py --domain all
python scripts/run_marketing_insights.py --domain all
python scripts/run_cross_domain.py
python scripts/run_reporting.py
```

### Standalone analyses

Each writes its results into `outputs/reports/` or `outputs/evaluation/`.

```bash
python scripts/run_ablation.py
python scripts/run_significance.py
python scripts/run_language_analysis.py
python scripts/run_auto_evaluation.py
python scripts/run_criterion_validity.py
python scripts/run_actionability.py
```

### Run the tests

The test suite needs no real datasets and makes no network calls, so it can verify an installation before any data is placed.

```bash
pytest tests/        # 272 tests across 16 files
```

## Key configuration

| Setting | Value |
|---|---|
| `RANDOM_STATE` | 42 |
| `TEST_SIZE` | 0.2 (stratified) |
| Proxy sentiment labels | rating ≤ 2 negative, ≥ 4 positive |
| SVM grid | C ∈ {0.5, 1.0, 2.0}, n-grams ∈ {(1,1), (1,2)}, 20,000 max features |
| VADER thresholds | ≥ +0.05 positive, ≤ −0.05 negative |
| LDA topic candidates | 5, 7, 10, 12, 15 |
| BERTopic | `all-MiniLM-L6-v2` embeddings, min topic size 15 |
| Transformer | `nlptown/bert-base-multilingual-uncased-sentiment`, max length 512 |
| LLM | `openai/gpt-oss-20b` via Groq, temperature 0.2 |
| LLM sample | 40 reviews per call, 300 characters per review |

The full configuration lives in a single module. See Appendix B.5 of the dissertation for details.

## Reproducibility notes

- Seeds are fixed (`RANDOM_STATE = 42`) and the data split reproduces identical per-class counts across runs.
- Dependency versions are pinned by **minimum** rather than exact version, which the ablation showed can change fitted-model results across environments.
- LLM output is **not deterministic**. Responses are cached by content hash in `outputs/llm/cache/` so reported results can be re-examined.

## Limitations

- The human evaluation was not completed, so usefulness and actionability are not directly measured.
- Only two product categories were studied, and the sentiment labels are proxies derived from star ratings.
- Competitive analysis (Prompt B) runs only where product and brand metadata exist (Electronics, not Beauty).
- Review data carries its own biases (self-selection, fake or incentivised reviews).
